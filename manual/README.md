# The Linux psX Manual

A guide to Linux psX: kernels for PlayStation consoles, the DiagnostiX hardware test, and the recorded results for each console.

**Start here:** Linux psX is in beta, and most testing so far has been on a PS4 Slim with a Baikal B1 southbridge. Check [whether your console is supported](02-compatibility.md) first. For a ready-made desktop, go to [Omarchy psX](https://omarchy.mrz.sh/).

The manual begins with a console that can already load a Linux payload. Preparing a console to run homebrew is outside its scope.
